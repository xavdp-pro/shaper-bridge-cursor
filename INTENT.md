# Intent — shaper-bridge-cursor

Let the human–AI tandem prepare useful context and precise missions, select an
engine through declared capabilities, inspect the resulting dialogue and learn
from actual outcomes. CLI-backed question answering with the normal Composer selection. Native CLI resume and portable dialogue replay are declared separately. Ask mode alone is not an operating-system access boundary.

A session can be prepared without generation, loaded with its existing history,
continued, or used as the source of a fresh session with deliberately selected
context. The tandem chooses rights and jurisdiction for each action within the
selected execution profile. OS / Runtime / Workspace describe responsibilities;
class, specialization and instance describe composition and materialization.
